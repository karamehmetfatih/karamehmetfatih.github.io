LsRTDv1

LsRTDv1 is a reference transcript dataset (RTD) for lettuce, Lactuca sativa cv. Saladin. It gives the lettuce community a transcript-level reference to quantify against, so that RNA-seq analysis in this crop can resolve individual transcript isoforms rather than collapsing them into whole-gene counts.

Alignment-free quantification is fast and precise, but it cannot be run without a reference transcriptome — and the isoform-level annotation lettuce had before this was thin. LsRTDv1 exists to remove that as a blocker.

What is in it

LsRTDv1 combines long- and short-read sequencing with publicly available transcriptome annotations, then filters the result to keep only transcripts with high-confidence splice junctions and high-confidence transcriptional start and end sites. The filtering is the part that matters: an RTD that keeps everything it assembles inflates the isoform count with artefacts, and quantification against a noisy reference is worse than not having one.

The dataset:

  • raises the number of transcript isoforms per gene in the lettuce genome from 1.4 to 2.7;
  • identifies novel genes, most of them long non-coding RNAs;
  • significantly increases the mapping rate of lettuce RNA-seq data.

What it makes possible

Validated on a lettuce time-series experiment — mock-inoculated and inoculated with the necrotrophic fungus Botrytis cinerea — LsRTDv1 enables:

  • detection of genes that are differentially alternatively spliced in response to infection;
  • transcript-specific expression changes, rather than a single number per gene.

Alternative splicing and post-transcriptional regulation during infection are largely unresolved in this crop, and a transcript-level reference is the precondition for studying them at all.

How to cite

Cite the paper if you are describing or building on the work:

Kara, M.F., Guo, W., Zhang, R. and Denby, K., 2024. LsRTDv1, a reference transcript dataset for accurate transcript-specific expression analysis in lettuce. The Plant Journal, 120(1), pp.370-386. DOI: 10.1111/tpj.16978. PMID: 39145419.

Cite the dataset if you quantified against it — this is the citation Dryad recommends, and the author order differs from the paper:

Denby, Katherine; Kara, Mehmet Fatih; Guo, Wenbin; Zhang, Runxuan (2024). LsRTDv1: A reference transcript dataset for accurate transcript-specific expression analysis in lettuce [Dataset]. Dryad. DOI: 10.5061/dryad.xwdbrv1m8.

Citing both is the safer habit — the paper explains how the resource was built and what it is good for, the dataset DOI pins the exact version your numbers came from.
